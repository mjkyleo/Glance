# Glance · 词根背单词 Logo 完整规范文档

> 基准图形：你选定的「G形词根生长符号」，线性连续标识，用于 Windows 桌面图标、Android 应用图标、网页 favicon、App 启动页，适配 Electron + Capacitor 跨端项目。
> 核心寓意：上方是字母 G（Glance），中间主节点 = 词根，向下分叉两支 + 末端节点 = 同源词缀、词根家族网络；线条连续、生长感，对应词根衍生、记忆关联、FSRS 记忆网络，「一瞥即触达词根脉络」。

## 一、SVG 矢量规范（文字详细说明，可直接交给设计师/自己写 SVG）

### 1. 画布基础

- 画布尺寸：`1024 × 1024` 正方形视口 `viewBox="0 0 1024 1024"`
- 坐标原点：左上角 `(0,0)`，图形**严格水平居中**；线稿本体高约画布 60%、宽约 42%（适配 Android 66dp 安全圆），放进图标底板时整体放大到约 70%
- 背景：SVG 本体**透明背景**，无填充、无渐变、无发光效果（发光是后期 UI 叠加效果，矢量源文件只保留干净线稿，方便复用）

### 2. 线条规范（最重要）

- 线条类型：**连续单路径（path）**，无分段拼接、无重叠描边，全部圆角端点（`stroke-linecap: round`），线条连接处平滑衔接
- 描边宽度：统一固定值 `stroke-width: 28`（在 1024 画布下，保证缩小到 16px favicon 依然可识别；如需缩放，等比同步线宽）
- 描边颜色：
  - 浅色模式矢量色值：`#222C34`（深墨蓝灰，低饱和，高级工具色）
  - 深色模式矢量色值：`#E6F0F8`（冷调月白，柔和不刺眼）
- 禁止：虚线、多重描边、内外轮廓、渐变描边、噪点、纹理；节点是**实心圆形填充，不是粗线条端点**

### 3. 图形结构分步坐标逻辑（中心基准点：`(512,512)`）

1. **上部 G 开口环**
   - 圆弧：圆心 `(512, 413)`，半径 `R=200`，开口在右侧（从 `-50°` 到 `+45°`，顺时针方向留口），开口足够宽，避免主干与圆环粘连
   - 短横：水平线从圆心 `(512, 413)` 向右至 `(712, 413)`，与圆弧末端保持呼吸间隙，长度等于半径
   - 含义：字母 G，品牌名称 Glance
2. **主干曲线**
   - 从短横右端 `(712, 413)` 垂直下行至 `(712, 566)`，再以两段二次曲线向左下收束到**中心词根节点**，形成克制的外扩弧线
   - 中心词根节点：圆心 `(512, 680)`，半径 `26`（≈1.8 倍描边宽度），实心填充，无描边
   - 含义：词根，整个词汇家族的核心基点
3. **分叉分支（左右严格对称）**
   - 从中心词根节点向下分出两条平滑外展弧线，左右镜像对称，弧度一致，弯曲角度克制，向外微微舒展，再平缓收向末端
   - 左右末端节点：左节点圆心 `(404, 798)`，右节点圆心 `(620, 798)`，半径 `22`，实心填充圆
   - 含义：同源词缀、派生词、词根分支，代表词根家族网络生长关系

   > ✅ 校验规则：左右两条弧线做镜像翻转，能够完全重合；整体视觉重心落在中心节点，不偏上、不偏下。

### 4. SVG 代码

仓库内的矢量源文件（由 `scripts/gen-icons.js` 生成，勿手改）：

- `assets/logo/glance-logo.svg` — 透明底 + `#222C34` 深色线稿
- `assets/logo/glance-logo-light.svg` — 透明底 + `#E6F0F8` 浅色线稿
- `assets/logo/glance-icon.svg` — 1024 深色圆角底板 + 浅色线稿（应用图标构图）

```
<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 1024 1024">
  <g fill="none" stroke="#222C34" stroke-width="28" stroke-linecap="round" stroke-linejoin="round">
    <path d="M 640.6 259.8 A 200 200 0 1 0 653.4 554.4"/>
    <path d="M 512 413 L 712 413"/>
    <path d="M 712 413 L 712 566 Q 712 634 644 662 Q 586 686 512 680"/>
    <path d="M 512 688 Q 484 712 454 746 Q 428 776 404 798"/>
    <path d="M 512 688 Q 540 712 570 746 Q 596 776 620 798"/>
    <g fill="#222C34" stroke="none">
      <circle cx="512" cy="680" r="26"/>
      <circle cx="404" cy="798" r="22"/>
      <circle cx="620" cy="798" r="22"/>

```

- 所有元素只使用：`<path>`（线条）+ `<circle>`（3 个节点）
- 不使用滤镜、feGaussianBlur、发光、阴影；发光效果是 APP 内渲染层叠加，不属于矢量 Logo 本体
- Android 矢量前景（`drawable/ic_launcher_foreground.xml`）使用同一组路径，整组缩放 `0.9` 后落在 66dp 安全圆内

## 二、App 图标｜圆角裁切安全区规范（适配 Android 自适应图标 + Windows 图标）

> 图标基底画布：1024×1024 正方形
> 区分两层：**安全内框（视觉安全区）、裁切外框（系统裁切边界）**

### 1. 边界定义

1. **系统裁切边界（外层圆角方形）**
   - 外框：1024×1024，圆角半径 `R=180`（Android 自适应图标标准圆角，Windows 应用图标圆角兼容）
   - 这一层是系统会自动裁切的区域，**图形不能贴这个边界**，系统会切掉溢出部分
2. **视觉安全区（强制内边距，所有图形必须落在这个框内）**
   - 安全框：距离外框四边向内收缩 14%
   - 安全框尺寸：744 × 744，居中放置，圆角跟随外框比例
   - ✅ 规则：Logo 图形的**最外侧顶点（G 圆环顶端、两个底部节点）全部落在安全框内部**，四周均匀留白，不会被系统圆角裁切切掉一部分图形
   - 留白均匀性：图形顶部到安全框上边距离 = 图形底部节点到安全框下边距离；左右两侧留白相等

### 2. 双平台适配细则

#### Android（Adaptive Icon 自适应图标）

- 分层：前景层 = 本 Logo 矢量图形；背景层 = 纯色背景（深色版：`#0F171D` 深墨黑蓝；浅色版：`#F7F9FA` 极浅灰白）
- 前景层严格放在安全区内，Android 系统会动态裁切、圆形蒙版、桌面不同形状蒙版，安全区保证任何桌面蒙版下 Logo 都完整、不被裁切
- 禁止：不要把背景渐变、发光放进前景层；发光是前景层叠加的可选 UI 效果，自适应图标前景尽量干净矢量，发光在 APP 启动页单独实现

#### Windows（Electron 桌面图标）

- Windows 图标支持多种尺寸：256/128/64/32/16px
- 安全区规则同样生效；小尺寸（32px、16px favicon）测试校验：G 轮廓、中间节点、两个分叉节点依然可以分辨，不会糊成一团
- Windows 图标圆角：系统自动圆角，依赖安全区留白，避免边缘被裁

### 3. 禁止项

- 图形顶点贴外裁切框
- 左右留白不对称
- 节点、线条溢出安全区
- 在图标本体里加入文字（文字只放在启动页，图标无文字）

### 4. 图标两套配色方案

- 深色图标（主用，推荐）：背景 `#0F171D`，Logo 图形 `#E6F0F8`，可选叠加微弱柔和外发光（仅 UI 渲染，矢量源不带发光）
- 浅色图标（备用）：背景 `#F7F9FA`，Logo 图形 `#222C34`，无发光，适合浅色主题桌面

## 三、启动页「Logo + 品牌文字 Glance」排版规范（跨端：Android / Windows Electron）

> 启动页比例：手机端 9:16 竖版；Windows 桌面端 16:9 横版，两套排版逻辑，核心对齐规则一致
> 风格：极简、安静、克制，和 App 整体 8 套主题设计语言统一，无多余装饰，符合离线学习工具的冷静气质

### 1. 基础排版原则（通用）

- 整体布局：**垂直居中排布，Logo 在上，品牌文字在下，两者之间设置固定呼吸间距，没有其他元素**
- 无副标题、无标语、无多余图形；只保留：Logo 图形 + 英文单词 `Glance`
- 背景：主启动页使用深色背景 `#0F171D`，可叠加极平缓径向渐变（中心微微亮，向四周缓慢变暗，不能有明显光斑），禁止噪点、纹理、霓虹强光
- 色彩：Logo 图形 `#E6F0F8`；文字 `#E6F0F8`，和 Logo 同色，明度统一，不使用第二种彩色

### 2. 字体规范（非常关键，和 APP 内字体体系对齐）

- 字体选择：无衬线现代字体，推荐：**Inter（跨端免费开源，Windows/Android 都支持）**，和你 App 内 UI 字体统一
- 文字内容：`Glance`，首字母大写 G，其余小写
- 字重：`Font Weight: 500 (Medium)`，不要粗黑（700+ 太重，破坏高级柔和感），不要细体（300 太淡，暗光下看不清）
- 字间距（letter-spacing）：`+0.06em`，轻微拉开字母间距，提升高级感，不拥挤
- 对齐方式：**文字和 Logo 图形中心对齐**（文字的中轴线，和 Logo 图形中轴线完全重合）

### 3. 间距与尺寸规则（分两个版本）

#### 版本 A｜移动端 Android 9:16 竖版启动页（最常用）

- 画布：宽 1080px × 高 1920px
- Logo 图形：高度占画布高度 22%，居中偏上
- Logo 底部 到 文字顶部 的距离：等于 Logo 图形高度的 32%（固定比例，不是固定像素，适配不同分辨率）
- 文字字号：文字宽度 ≈ Logo 图形宽度的 75%，文字不能宽过 Logo，视觉上 Logo 是视觉主体，文字是辅助标识
- 底部留白：文字底部到画布底边距离，大于 Logo 上方留白，重心稳定，不会顶到屏幕底部

#### 版本 B｜Windows Electron 16:9 横版启动页

- 画布：宽 1920px × 高 1080px
- Logo 图形：高度占画布高度 28%
- Logo 和文字间距比例和移动端保持一致；文字宽度为 Logo 宽度 75%
- 整体垂直居中，适合窗口启动加载画面

### 4. 发光效果规范（可选，启动页专属）

- 给 Logo 图形添加**极柔和的外发光**：模糊半径小，透明度低，朦胧呼吸感，不是刺眼霓虹
- 文字**不加发光**，文字保持纯色，避免画面杂乱
- 加载逻辑：启动页可以做淡入动画：背景先显示 → Logo 淡入 → 文字缓慢淡入，无跳动、无夸张动效，匹配 App 安静的学习氛围

### 5. 浅色模式备用启动页（适配 App 浅色主题）

- 背景：`#F7F9FA`
- Logo 与文字颜色：`#222C34`，**完全去掉发光**，干净线稿风格
- 排版比例、字体、间距和深色版完全一致，只反转色彩

## 四、资源文件与重新生成

矢量几何只在 `scripts/gen-icons.js` 里维护一份，所有平台资源由它派生：

```bash
npm install --no-save sharp png2icons   # 仅生成时需要，不写入依赖
node scripts/gen-icons.js
```

生成内容：

| 位置 | 用途 |
| --- | --- |
| `assets/logo/glance-logo{,-light}.svg` | 透明底线稿（深/浅），文档与二次设计用 |
| `assets/icons/app-icon.png` | 1024 圆角底板图标（Electron 窗口图标） |
| `assets/icons/app-icon.ico` | Windows 图标，含 256/128/96/72/64/48/32/24/16 |
| `assets/icons/app-icon.icns` | macOS 图标 |
| `assets/icons/app.iconset/` | macOS iconset 源图 |
| `android/.../mipmap-*/ic_launcher{,_round}.png` | Android 传统图标（48–192px） |
| `android/.../mipmap-*/ic_launcher_foreground.png` | Android 自适应前景（108–432px，透明底） |
| `android/.../drawable*/ic_launcher_foreground.xml` | Android 矢量前景（缩放 0.9 落在安全圆内） |
| `android/.../drawable*/splash.png` | 启动图（深色 `#0F171D` + 浅色标记，Logo 高 22%） |

App 图标构图：深色圆角底板 `#0F171D`（圆角 180）＋浅色标记 `#E6F0F8`，标记整体放大到 1.15 倍；Android 自适应图标背景同为 `#0F171D`，并已加入 `<monochrome>` 以支持系统主题图标。
